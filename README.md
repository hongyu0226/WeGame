# 給寶貝的禮物大作戰 ♡ 遊戲使用與設定說明

這是一個為女友精心打造的日系繪本風一頁式互動小遊戲，完全採用 **純 HTML + CSS + JavaScript** 開發，**免安裝任何後端或 Node.js 環境**，在任何瀏覽器（手機、平板、電腦）雙擊即可直接運行！

---

## 🎮 如何開啟遊戲

### 方法一：直接點擊開啟
1. 在資料夾中找到 `index.html`。
2. 用滑鼠雙擊，或右鍵選擇「使用 Google Chrome / Safari / Edge 開啟」即可！

### 方法二：部署成線上網址（傳給女友手機玩）
可直接將本資料夾內的檔案上傳至：
- **GitHub Pages**（免費靜態網站託管）
- **Vercel** / **Netlify**（直接將資料夾拖曳進去即可產生專屬網址）
- **Cloudflare Pages**

---

## 📝 如何修改題目與答案？

所有題目、選項、正確答案與提示都集中在 **`data.js`** 檔案中！  
只要用任何文字編輯器打開 `data.js`，就能輕鬆修改：

```javascript
{
  id: "quiz_kiss",
  prizeId: "kiss",
  difficulty: 1,
  // 1. 修改題目文字：
  question: "寶貝～在我們相處的時光裡，每次見面分開前，哪一個小動作是絕對不能漏掉的？♡",
  // 2. 修改四個選項：
  options: [
    { id: "A", text: "選項 A 文字" },
    { id: "B", text: "選項 B 文字" },
    { id: "C", text: "選項 C 文字" },
    { id: "D", text: "選項 D 文字" }
  ],
  // 3. 設定正確選項 ID ("A" / "B" / "C" / "D")：
  correctOptionId: "B",
  // 4. 第一次答錯時的溫柔提示：
  hint: "提示：是充滿愛意、暖呼呼又帶有啾啾聲的甜蜜魔法喔！💋",
  // 5. 第二次若仍答錯時公布的正解說明：
  answerExplanation: "正解是「抱一個加甜蜜啾啾（Kiss）」！這可是專屬我們的默契呀♡",
  // 6. 答對時的解鎖驚喜文字：
  successMessage: "答對啦！不愧是我的寶貝！這份甜蜜 Kiss 驚喜立即送給妳！♡"
}
```

## ✨ 規格與特色功能

- **日系繪本風視覺**：
  - 專屬色票：和紙白背景、墨灰粗線條、珊瑚粉、山吹黃、水色、若竹綠。
  - 3px 墨灰粗線框 ＋ 大圓角 ＋ 4px 硬邊陰影。
  - Google Fonts Huninn（粉圓體）可愛溫柔字型。
- **自由順序闖關**：女友每刮開一張刮刮樂，即可在網頁中挑選同名禮物挑戰，無固定關卡順序限制。
- **作答保護機制**：
  - 每題最多正式作答 2 次。
  - 第一次答錯顯示專屬線索與提示，不公開答案。
  - 答對立即解鎖禮物並撒花慶祝！
  - 第二次仍答錯才會公布正確答案，該禮物鎖定但不影響其他禮物。
- **進度自動儲存**：使用瀏覽器本地儲存（localStorage），即使重新整理或關閉分頁，解鎖成果與剩餘次數也不會遺失。
- **音效與動畫**：內建 Web Audio API 音效合成器與慶祝彩花特效，支援一鍵靜音。
- **響應式排版**：針對手機螢幕特別優化按鈕點擊大小與雙欄/單欄自動切換。
